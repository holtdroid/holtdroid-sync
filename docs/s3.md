# holtdroid-s3-sync

Brings APKs from an S3 bucket into [Holtdroid](https://github.com/kriakiku/holtdroid).
It works in two modes, and you can run both at once:

- **copy**: copies the APKs that match your rules into a folder or another S3
  bucket, which Holtdroid lists as a read-only source. The copies stay
  available when the AWS session ends.
- **broker**: serves temporary AWS credentials in the ECS container
  credentials format, so Holtdroid can list the bucket itself (S3 source
  with `credentialsURL`). Nothing is copied, and the builds disappear from
  the portal while there is no session.

Both modes can use AWS IAM Identity Center (SSO) with no AWS CLI and no
local browser. When a login is needed, the job asks a person to approve a
device code in the browser. It sends the link through
[shoutrrr](https://github.com/nicholas-fedor/shoutrrr) (Slack, Telegram,
Discord, Matrix, ntfy, email, webhooks, …) and writes it to its log and
`/status`. It then keeps the session alive with refresh tokens for as long
as your Identity Center allows (the session duration your admins set,
typically 8 hours to 7 days). After that it asks again.

A code is valid for about ten minutes. If nobody approves it, the next code
(and message) comes after `notify.remind`, one hour by default, so the
channel doesn't fill up.

## Rules

`source.include` is a gitignore-style list, evaluated against keys relative
to `source.prefix`:

```yaml
include:
  - /releases/*          # anchored: releases/ and everything below it
  - "!/releases/night/*" # ...except nightly builds
  - "*-qa.apk"           # a name pattern matches at any depth
```

- `*` matches within one path segment, and `**` spans directories.
- A pattern that matches a directory matches everything below it.
- `!` excludes.
- The last matching pattern wins.
- An empty list takes every `*.apk`. A list that starts with an exclusion
  starts from "everything".
- Hidden files and directories are ignored.

## What copy writes

Copy keeps the source layout under the target:

```
{key relative to source.prefix}.apk
{…}.apk.meta.json   # origin "s3", uploadedAt = LastModified, link to the AWS console
{…}.apk.icon.png    # the launcher icon re-rendered at 256 px, when there is one
```

If the bucket already has `x.apk.meta.json` or `x.apk.icon.png` next to an
APK, they are used: the sidecar is merged with the defaults above, and the
icon is decoded and re-rendered.

A build is copied again when its size changes or the source object is newer
than the copy. With `prune` (the default), copies of builds that are gone
from the bucket or no longer match the rules are deleted, but only after a
complete listing. Give the job its own target prefix, because it owns
everything there.

## New build announcements

`notify.builds` sends one message per copy pass that copied anything, through
the same shoutrrr URLs. For each build, up to ten of them, it lists:

- name, version and package;
- key and size;
- **Quick launch** and **Launch** links into the portal.

Builds whose object is older than `maxAge` are left out, so the first copy of
an existing bucket stays quiet. Copies that already exist after a restart
aren't announced again.

## Configuration

A YAML file (`--config`), overridden by `HOLTDROID_S3_SYNC_*` environment
variables. `__` separates levels, and lists are comma-separated.

```yaml
source:
  bucket: work-apks
  prefix: android/
  region: eu-west-1
  endpoint: ""              # for S3-compatible stores; empty = AWS
  pathStyle: false
  include: ["/releases/*", "!/releases/night/*"]
  auth:
    type: sso               # sso | static | default (env, ~/.aws, IRSA, instance role)
    sso:
      startURL: https://acme.awsapps.com/start
      region: eu-west-1     # the Identity Center region
      accountID: "123456789012"
      roleName: ApkReader   # the permission set
      cacheFile: /data/sso/tokens.json   # keep the session across restarts
    static:
      accessKey: env:AWS_ACCESS_KEY_ID
      secretKey: env:AWS_SECRET_ACCESS_KEY
copy:
  enabled: true
  interval: 5m
  prune: true
  target:                   # same shape as Holtdroid's storage
    type: s3                # filesystem | s3
    s3: { endpoint: https://s3.example.com, bucket: holtdroid, prefix: work, accessKey: env:S3_ACCESS_KEY, secretKey: env:S3_SECRET_KEY }
broker:
  enabled: false
  token: env:BROKER_TOKEN   # clients send it in the Authorization header
listen: ":8080"             # /healthz, /status (token), /credentials (token, broker only)
notify:
  urls:                     # shoutrrr URLs; they hold tokens, so they are secret references
    - env:NOTIFY_URL        # e.g. slack://xoxb:<bot token>@C0123ABCD, telegram://<token>@telegram?chats=<id>
  remind: 1h                # least time between two login codes while nobody approves
  builds:                   # announce new copies (copy mode only); empty urls = off
    urls: [env:BUILDS_NOTIFY_URL]
    portalURL: https://holtdroid.example.com   # adds Quick launch / Launch links
    source: s3              # the Holtdroid source that lists the copy target
    maxAge: 24h             # builds older than this (e.g. a first copy) are not announced; 0 = all
secrets:
  openbao: { address: https://bao.example.com, kubernetes: { role: holtdroid-s3-sync } }
```

The role needs `s3:ListBucket` on the bucket (with the prefix) and
`s3:GetObject` on its objects.

### Direct reading in Holtdroid

```yaml
sources:
  - name: work
    type: s3
    readOnly: true
    include: ["/releases/*", "!/releases/night/*"]
    s3:
      endpoint: https://s3.eu-west-1.amazonaws.com
      region: eu-west-1
      bucket: work-apks
      prefix: android
      credentialsURL: http://holtdroid-s3-sync:8080/credentials
      credentialsToken: env:BROKER_TOKEN
```

## The token cache

`cacheFile` stores the OIDC client registration and the access and refresh
tokens, with mode `0600`. These are credentials: put the file on a small
private volume. Without a cache file, every restart needs a new login.

## Running

```sh
holtdroid-s3-sync --config config.yaml          # copy loop and/or broker
holtdroid-s3-sync --config config.yaml --once   # one copy pass (static/default auth or a cached session)
```

Image: `ghcr.io/kriakiku/holtdroid-sync` (all jobs; run `holtdroid-s3-sync`).
Helm chart: `deploy/helm/holtdroid-sync` with `job: s3`, see the
[README](../README.md#deploying).
